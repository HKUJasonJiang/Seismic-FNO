# O3 Generalization

Paper role: `§5.2` and `§5.3`.

Purpose: test whether trained models generalize to out-of-distribution ground motions and unseen PGA amplitudes.

Work packages:

1. OOD descriptors for K-NET and classic GMs.
2. Zero-shot evaluation using full-data and reduced-data checkpoints where available.
3. PGA extrapolation: train on PGA 1-10 m/s^2 and test at 15/20 m/s^2.

Expected paper deliverables:

- OOD PCA/histograms.
- Zero-shot time/spectral overlays.
- R2-vs-PGA degradation curves.
- Draft text for `§5.2-§5.3`.
